# Tasks — hook timing

- [ ] **Timing funnel.** `HookRunner` gains one timing wrapper around the per-handler call (the `CallVoidAsync`/`CallAsync` funnel): monotonic `Stopwatch.GetTimestamp`/`GetElapsedTime`; per (extension id, hook) aggregate `{calls, totalMs, lastMs, maxMs, slowCount, timedOut, cancelled}` updated thread-safely (`Interlocked` on entry fields) and allocation-free on the hot path (entries reused per key); cancelled dispatches excluded from `maxMs`/`slowCount`/warning; timeouts count; child runs land in the same session aggregate; snapshot exposed as `HookTimings` (public type; `PublicAPI.Unshipped.txt`).
- [ ] **Metrics.** `System.Diagnostics.Metrics` histogram on meter `Lunate.Extensibility` (unit ms, tags `extension` + `hook`, tag array cached per entry), recorded where the aggregate updates; no exporter work.
- [ ] **Warn once + notice.** `HookRunnerOptions.SlowHookThreshold` (default 500 ms); first crossing per (extension, hook) logs one warning naming the extension, the hook, the elapsed time and the threshold and pointing at `/extensions`; later crossings increment `slowCount` only; a slow-hook event lets the interactive session render one dim notice (no subscriber → log only, never stdout).
- [ ] **Preparation exclusion.** A small optional interface on handlers lets a handler report one-time preparation (the remote lazy start + `initialize` handshake); the runner subtracts it from that dispatch's elapsed and it never feeds `maxMs`/`slowCount`/warning. The remote extension measures its start+handshake and exposes the most recent duration.
- [ ] **View.** Loaded `/extensions` segments append `hook <Hook> max <ms> ms, <slowCount>/<calls> slow` (only when something crossed) and remote extensions append `start <ms> ms`; `--json` gains `hookTimings` (`{hook, calls, totalMs, lastMs, maxMs, slowCount, timedOut, cancelled}`) and `startMs`; the register-only subcommand stays unchanged (no dispatches). Culture-invariant numbers.
- [ ] **Remote labeling.** Docs + spec state: a remote interceptor's time includes the round trip; a remote observer's time is the host-side send time (no round trip).
- [ ] **Tests.** Unit: aggregation per pair; warn-once + slowCount; cancelled excluded / timeout counted; child runs aggregated; metrics histogram via `MeterListener`; zero-extension dispatch overhead unchanged (Perf-category budget style); preparation subtraction; threshold option honored. View: segment suffix + JSON contract + startMs; inspect mode carries no `hookTimings`; de-AT pass unchanged. Remote: cold-start exclusion via a scripted child.
- [ ] **Docs.** `docs/spec/extensibility.md` per-hook sentence describes what landed; `docs/extensions-remote.md` notes the round-trip vs send-time contract (one sentence).
- [ ] **Gate + review.** Full `verify.sh` (both culture passes), adversarial review, archive.
