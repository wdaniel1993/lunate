# Lunate documentation

This page answers where to start reading. The short answer: Lunate's documentation is organised around
what you want to do, not around the components that do it — pick a task group below, and each page
states its answer in the first paragraph and links one hop to the page that owns the detail.

New here? [Quickstart](quickstart.md) installs Lunate and walks the first run, and
[How Lunate works](how-lunate-works.md) gives the mental model before the detail.
